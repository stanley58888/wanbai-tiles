# 完百計畫 地圖圖磚（魯地圖 MOI.OSM）

這裡是「完百計畫」App 使用的登山地圖圖磚，由 **魯地圖 MOI.OSM - Taiwan TOPO**（Rudy Chung）轉成點陣圖磚，只涵蓋 App 內建百岳路線周邊（縮放 11–15）與台灣全島總覽（縮放 11–12）。

- 魯地圖官方網站與說明：https://rudymap.tw/
- 魯地圖作者同意 App 使用：https://github.com/alpha-rudy/taiwan-topo/issues/68
- 原始地圖版本：MOI.OSM - Taiwan TOPO（rudymap.tw 2026-10 發行版），以 [mapsforgesrv](https://github.com/telemaxx/mapsforgesrv) 依官方 MOI_OSM 樣式轉檔

請勿將本圖磚當作魯地圖的發佈來源；要下載魯地圖請到 https://rudymap.tw/ 。
